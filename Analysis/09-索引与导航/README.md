## 导航系统设计原则

### 1. 可达性
- 任意核心文档从根入口 [00-主题树与内容索引](../00-主题树与内容索引.md) 可达
- 索引深度 ≤ 3 跳（根 → 体系 README → 专题文档）

### 2. 双向链接
- 每个文档包含「前置/后续」声明，形成知识网络
- 相关文档之间通过 See Also 互相引用

### 3. 一致性
- 所有链接遵循统一的命名与路径规范
- 断链率目标 = 0，引用可达性 100%
