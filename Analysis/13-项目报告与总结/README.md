## 质量保证框架

### 验收标准

- **覆盖度**：L1/L2 覆盖率 ≥ 95%，L3 知识单元覆盖率 ≥ 80%
- **标准映射**：42010/25010/15288/12207 条款映射完成率 ≥ 90%
- **完整性**：每个矩阵单元有证据链接（文档/模型/流程/度量）
- **链接质量**：断链率 = 0；引用可达性 100%
- **一致性**：无严重错误，普通问题一周内清零

### 评审节奏

- **周更**：矩阵与周报至少更新一次
- **高优先缺口 TTR** ≤ 2 周
- **随机抽样**：5% 矩阵行深度审计，不合格项下周关闭
